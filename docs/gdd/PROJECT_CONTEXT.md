## 프로젝트 한눈에 보기

- **가제:** LOT 06
- **장르:** 1인칭 리미널 스페이스 탐색 공포
- **목표 플레이 시간:** 20–30분
- **개발 범위:** 1인 개발, 약 1–2개월
- **핵심 조작:** 걷기, 시점 이동, 문 열기, 간단한 조사
- **핵심 목표:** 사라진 출구를 대신할 현실 연결점을 찾아 탈출한다.
- **전투·추격·게임 오버:** 없다.

주인공은 정체불명의 수영장 공간에서 가구를 현실 창고로 반출해 팔아 왔다. 여섯 번째 물건인 `LOT 06`을 내보낸 직후 출구가 벽으로 바뀌고, 수영장 공간은 과거 반출품과 현실 창고를 조금씩 복제하기 시작한다.

## 플레이 경험의 불변 조건

1. 가구는 퍼즐, 운반 시스템, 무기가 아니다. 공간이 현실을 베끼고 있다는 **증거**다.
2. 플레이어는 걷고, 문을 열고, 공간 변화를 관찰하며 탈출한다.
3. 공포는 몬스터나 점프 스케어가 아니라 비어 있던 공간의 누적된 변화, 반복, 잔향, 현실 경계의 붕괴에서 나온다.
4. 막다른 길은 처벌하지 않는다. 짧은 변형 구간을 거쳐 30초 안에 주 동선으로 합류시킨다.
5. 다음 방향은 빛·소리·화살표 중 최소 두 단서가 겹쳐 안내한다.
6. 변화는 눈앞에서 갑자기 생성시키지 않는다. 문이나 코너를 지난 뒤 “조금 전과 달라진 상태”로 발견하게 한다.

## 세계 규칙

- 공간은 출구가 현실 창고로 열릴 때 가구·선반·조명·소리·구조를 관찰한다.
- 나타난 가구는 현실 물건이 되돌아온 것이 아니라 공간의 기억이 만든 복제품이다. 원래 위치에 되돌려 놓아도 해결되지 않는다.
- `LOT 06` 반출이 현실을 재현하기에 충분한 정보가 쌓인 임계점이다.
- 복제는 정확하지 않다. 예: 선반 아래 배수구, 전원 없는 스탠드, 셔터 너머 또 다른 창고, 비닐 안의 물.

## 30분 진행 뼈대

| 구간 | 변화와 플레이어 이해 |
| --- | --- |
| 0–3분 | `LOT 06` 반출 직후 출구가 소실된다. 목표는 탈출뿐이다. |
| 3–8분 | 익숙한 수영장 길에서 작은 오류와 단서를 발견한다. |
| 8–12분 | 메인 풀에서 `LOT 02`를 발견한다. 반출품이 복제됐음을 의심한다. |
| 12–18분 | 가구가 비정상적인 배치로 증식하고 문·복도·수위가 달라진다. |
| 18–24분 | 창고 선반·비닐·조명·카트가 수영장으로 침투한다. 공간이 현실을 배운다는 사실을 이해한다. |
| 24–28분 | 현실 창고와 닮은 복제품에서 `LOT 07`과 `LOT 06`을 마주한다. |
| 28–30분 | 실제 창고로 돌아온 듯하지만 물방울·형광등·카트 소리로 여운을 남긴다. |

공간은 **비어 있는 상태 → 가구가 침투한 상태 → 창고와 혼합된 상태**의 세 단계로 변한다. 새 맵을 계속 늘리지 말고, 같은 공간의 조명·문 연결·가구 배치·사운드·재질을 바꿔 진행감을 만든다.

## MVP와 범위 제한

우선 완성할 것은 시작 출입구 소실, 메인 풀과 복도 한 세트, 재방문 상태 변화, `LOT 02` 첫 등장, 수영장·창고 혼합 최종 공간, 현실 창고 귀환 엔딩, 기본 사운드와 리버브다.

다음은 범위 밖이다.

- 자유 가구 물리·반복 운반
- 인벤토리, 아이템 조합, 정답형 관찰 퍼즐
- 몬스터 AI, 전투, 추격
- 긴 문서 수집, 절차적 맵, 실시간 유체 시뮬레이션, 다중 엔딩

## 구현·테스트 판단

- 필요한 시스템: 1인칭 이동, 문 상호작용, 트리거 기반 공간 상태 전환, 진행·방문 횟수 기록, 문 연결과 루프, 오브젝트 활성화, 구역별 리버브·환경음, 조사 UI·자막·음량 조절, 체크포인트 저장.
- 핵심 자산은 수영장·창고 환경 모듈과 의자·소파·식탁·수납장·스탠드 다섯 종류다. 재질·젖음·흠집·가격표를 바꿔 재사용한다.
- 첫 그레이박스의 임시 기준: 출구 소실 뒤 30초 안에 80%가 다음 단서를 따라가고, 70%가 `LOT 02` 변화와 24분 구간의 현실 복제를 설명하며, 막다른 길 평균 복귀 시간은 30초 이내다.

## 미정 또는 확인이 필요한 사항

- 목표 플랫폼, 입력 장치, 배포 형태, 성능 기준은 기획서에서 미정이다.
- 체크포인트 위치와 재개 방식은 첫 그레이박스 테스트 뒤 결정한다.
- 현재 프로젝트 파일은 Unreal Engine 5.5를 사용하지만, 위의 플랫폼·성능 결정까지 확정했다는 뜻은 아니다.
